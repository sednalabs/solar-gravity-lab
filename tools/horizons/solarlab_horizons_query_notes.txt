Suggested Horizons generation settings for external agents:

- use vector output, not elements
- use one epoch for every body
- use one center for every body
- use one frame for every body
- use TDB
- use geometric vectors (no light-time correction)
- export in KM-S and convert to m and m/s before writing the bundle

Suggested parameter set:

EPHEM_TYPE=VECTORS
VEC_TABLE=2
TIME_TYPE=TDB
REF_SYSTEM=ICRF
VEC_CORR=NONE
OUT_UNITS=KM-S
CSV_FORMAT=YES
